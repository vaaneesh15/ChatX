# TapX Clicker

Статический веб-кликер для iOS. Работает без сервера, сохраняет прогресс в `localStorage` и подходит для GitHub Pages.

## Что внутри

- `index.html` — разметка приложения.
- `styles.css` — адаптивный интерфейс, safe-area для iPhone, светлая и темная темы.
- `app.js` — логика кликов, улучшений, автокликера, офлайн-прогресса и сохранения.
- `manifest.webmanifest` и `service-worker.js` — PWA-режим и кеширование после публикации по HTTPS.
- `assets/` — иконки приложения.

## Как запустить локально

Открой `index.html` в браузере. Для проверки PWA-режима лучше запустить локальный сервер:

```bash
python3 -m http.server 8080
```

После этого открой `http://localhost:8080/clicker-ios-web/`.

## Как выложить на GitHub Pages

1. Создай новый репозиторий на GitHub.
2. Загрузи содержимое папки `clicker-ios-web` в корень репозитория.
3. Открой `Settings` → `Pages`.
4. В `Build and deployment` выбери `Deploy from a branch`.
5. Укажи ветку `main` и папку `/root`.
6. После публикации открой ссылку GitHub Pages на iPhone.

На iOS можно нажать `Поделиться` → `На экран Домой`, чтобы запускать кликер как приложение.
